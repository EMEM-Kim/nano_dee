# AI Agent 활용 프로젝트 — CareLens

## 1. 프로젝트 소개

AI 코딩 에이전트인 **ChatGPT Codex**를 활용해 건강보험 청구 현황을 확인하는 CareLens 대시보드를 제작했다. 많은 명세서를 표만으로 확인하기 어려운 문제를 해결하기 위해 청구 규모·상병 구성·월별 수요를 한 화면으로 구성했다.

이 프로젝트의 AI 활용 범위는 요구사항 정리, 코드 작성·수정, 검증과 문서화이다. 최종 결과물은 브라우저에서 JavaScript로 집계하는 정적 웹 대시보드이며, 실행 중 LLM을 호출하는 서비스는 아니다.

## 2. 제작 목적

병원 경영기획 담당자가 월초 경영회의 전에 핵심 지표를 빠르게 확인하도록 구성했다. SQL에서 학습한 집계 기준을 시각화에 적용하고, 다른 사람이 링크만으로 결과를 열어 볼 수 있도록 배포하는 것이 목적이었다.

## 3. 사용 기술

| 기술 | 역할 |
|---|---|
| ChatGPT Codex | AI 코딩 에이전트를 활용한 제작·수정·검증 |
| Python, openpyxl | 강의 XLSX 읽기와 코드 연결, 독립 집계 |
| HTML, CSS, JavaScript, SVG | KPI·차트·필터·CSV 구현 |
| Node.js | HTML 빌드와 집계 테스트 |
| GitHub Actions, GitHub Pages | 검사 자동화 및 공개 배포 |

## 4. Agent 구조

제작 과정에서는 요구사항과 데이터 구조를 AI 코딩 에이전트에 전달하고, 생성한 코드의 결과를 검산한 뒤 수정 사항을 반영했다. 재현에 필요한 입력·계산식·검산값은 [프롬프트 문서](docs/prompts.md)에 정리했다.

| 단계 | 입력·처리 | 결과 |
|---|---|---|
| 요구사항 정리 | 대상 독자, KPI, 차트, 필터 정의 | 구현 명세 |
| 데이터 준비 | XLSX의 claim·institution·sick_master·code_table 연결 | 가공 데이터와 독립 집계 |
| 코드 제작 | 화면 및 집계 로직 작성·수정 | HTML·CSS·JavaScript |
| 검증·개선 | 전체·필터 결과를 기준값과 비교 | 검증된 집계 로직 |
| 빌드·배포 | HTML에 데이터·스타일·스크립트 포함 | 공개 대시보드 |

완성된 대시보드는 HTML에 포함된 데이터를 읽고, 필터 선택에 따라 KPI와 차트를 다시 계산한다. 제작에 사용한 AI 에이전트와 결과물의 실행 구조를 구분했다.

## 5. 주요 기능

- 명세서 수, 총 진료비, 고유 수진자 수 KPI
- 주상병별 TOP 8과 기관 종별 건당 진료비 비교
- 호흡기 질환의 24개월 청구 추세
- 연도·기관 종별·상병 범위 필터와 초기화
- 월별 원자료 표 및 UTF-8 BOM CSV 다운로드
- 데이터와 코드를 포함한 단독 실행 HTML

## 6. 내가 수행한 내용

과제 범위를 SQL과 웹 결과물로 정리하고, 제출할 HTML·공개 URL·재현 프롬프트를 요청했다. 생성된 결과물을 검토하면서 파일 구조와 README의 설명을 보완하도록 요구했고, 문서의 불필요한 안내와 혼합된 문체를 수정했다.

GitHub Pages 설정을 진행하고 1·2일차 과제를 제출했다. 회고의 도입부는 직접 수정했으며, 구현 설명보다 강의에서 배운 점과 백엔드·DB 분야에 적용할 아이디어가 드러나도록 보완했다. 코드 작성과 집계 검증에는 ChatGPT Codex를 활용했다.

## 7. 테스트 및 개선

| 검증 항목 | 기준 |
|---|---|
| 전체 집계 | 38,375건 / 3,293,580,300원 / 2,970명 |
| 2025년·의원 필터 | 15,374건 / 544,714,500원 / 2,705명 |
| 월별 집계 | 24개월 |
| 재현 빌드 | HTML 생성 및 배포 폴더 구성 |

필터 적용 후 고유 수진자 수를 다시 계산하도록 구성했다. 기관 종별명은 코드 유형을 지정해 연결하고, 계절 비교는 기간 길이에 영향을 받는 총합 대신 월평균을 사용했다. 화면에서 집계 기준과 데이터 출처를 확인할 수 있도록 설명을 추가했다.

저장소 루트에서 Node.js 22 이상으로 실행한다.

```sh
node web/test.mjs
node web/build.mjs
```

원자료 갱신과 소스 파일별 역할은 [구현 문서](docs/implementation.md)에 정리했다.

## 9. 배운 점

AI에 화면 제작을 요청할 때는 디자인뿐 아니라 조인 키, 지표 계산식, 중복 제거 기준과 검산값까지 전달해야 했다. 결과물이 실행되는지와 숫자가 정확한지는 따로 확인해야 한다는 점을 배웠다.

백엔드·DB 개발에 적용한다면 API 요청량, 오류율, 응답시간을 확인하는 운영 대시보드로 확장할 수 있다. 현재의 정적 데이터에서 나아가 API나 데이터베이스의 변경 사항을 화면에 반영하는 것이 다음 적용 아이디어이다. [회고 전문](docs/reflection.md)에 학습 경험을 정리했다.
