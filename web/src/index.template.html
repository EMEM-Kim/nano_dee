집계 기준

명세서는 행 수, 진료비는 rvd_rpe_tamt_amt 합계, 수진자는 jid의 고유 개수입니다. 진료월은 recu_fr_dd 기준입니다. claim과 institution은 yid로, 상병명은 sick_master의 sickcd로 연결합니다. 기관별·월별 수진자 수를 합산하면 중복될 수 있습니다.

수업 원본으로 계산

명세서와 환자·진료비는 수업용 가상 데이터이며 실제 진료 기록이나 전국 의료통계가 아닙니다. 상병명은 제공된 마스터를 사용했습니다. 정적 스냅샷으로 Supabase 실시간 연동은 적용하지 않았습니다.
