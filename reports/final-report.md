# 최종 결과 문서

## 1. 결과물 개요

SQL 실습·과제와 AI 코딩 에이전트를 활용한 CareLens 대시보드를 제작했다. SQL에서 분석 기준과 집계 방법을 학습하고, 건강보험 청구 데이터를 웹 화면에서 탐색할 수 있도록 구성했다.

| 결과물 | 내용 | 링크 |
|---|---|---|
| SQL 실습 | 조건 조회, 종별 집계, 방문 간격, 코호트·병기 분석 | [실습 SQL](../sql/practice/practice_1-5.sql) |
| SQL 과제 | 외래·입원, 상병별 집계, 재방문, 사망 기록 분석 | [과제 폴더](../sql/assignments/) |

| CareLens | KPI·차트·필터·CSV 다운로드 | [실행 화면](https://emem-kim.github.io/nano_dee/dashboard.html) |
| 제작 기록 | 구조, 사용 기술, 검증, 재현 프롬프트 | [웹 README](../web/README.md) |

## 2. 제작 목적과 과정

병원 경영기획 담당자가 월초에 청구 규모와 상병 구성, 계절별 진료 수요를 확인하는 상황을 설정했다. 청구·기관·상병 코드 데이터를 연결하고, 명세서 수·총 진료비·고유 수진자 수를 지표로 선정했다.

SQL 실습은 MySQL에서 수행했다. 웹 결과물은 강의 XLSX를 Python으로 가공한 뒤 HTML·CSS·JavaScript·SVG로 구현했다. ChatGPT Codex를 제작에 활용했으며, 화면 요구사항과 결과물 구성에 대한 피드백을 반영했다. 완성된 HTML은 GitHub Pages로 배포했다.

## 3. 주요 결과

전체 청구는 **38,375건**, 총 진료비는 **3,293,580,300원**, 고유 수진자는 **2,970명**이었다. 급성 기관지염(J209)이 5,285건으로 가장 많았고, 호흡기 청구의 11~3월 월평균은 6~9월의 약 2.17배였다.

SQL 과제에서는 2025년 7월 외래 1,450건을 조회했고, E119 외래의 90일 초과 재방문 1건을 확인했다. 폐암 분석은 2010~2017년 최초 진단 코호트 6,873명을 대상으로 수행했다. 상세 쿼리와 수치는 [SQL README](../sql/README.md)에 정리했다.

## 4. 검증 및 개선

| 검증 대상 | 확인 결과 |
|---|---|
| 전체 KPI | 38,375건 / 3,293,580,300원 / 2,970명 |
| 2025년·의원 필터 | 15,374건 / 544,714,500원 / 2,705명 |
| 월별 집계 | 24개월 |
| HTML 빌드 | 대시보드·그래프 생성 및 배포 폴더 구성 |
| 배포 | GitHub Pages 배포 성공 기록 확인 |

지표별 계산 기준을 명시하고, 필터 변경 시 수진자 수를 다시 중복 제거하도록 구성했다. 계절별 비교에는 월평균을 사용했다. 문서는 SQL·AI 활용·최종 보고서로 나누고, 각 README에서 코드와 결과를 연결했다.

## 5. 결과 해석과 확장 방향

사용 데이터는 수업용 가상·합성 데이터이다. 기관 종별 평균 진료비는 진료의 질을 뜻하지 않으며, 사망 기록 비율은 추적 누락과 검열을 보정한 생존율이 아니다.

대시보드는 HTML에 데이터를 포함한 정적 방식이다. 다음에는 백엔드 API나 데이터베이스와 연결해 데이터 갱신을 반영하고, API 요청 수·오류율·응답시간을 확인하는 운영 화면에 적용하고 싶다.
