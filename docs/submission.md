# 웹 대시보드 과제 제출용 답안

## 과제 1 — 관심 주제 그래프

### 주제 및 설명
호흡기 질환 청구의 월별 변화를 살펴보는 꺾은선 그래프를 제작했다. 관심 질문은 “호흡기 질환 청구는 겨울철에 더 많을까?”이다. 시간 순서의 변화를 보여주기 위해 꺾은선 그래프를 선택하고, 세로축은 0부터 시작하도록 했다. 데이터는 강의에서 제공한 kr_claims 가상 명세서다.

### HTML 코드
`graph.html` 파일을 1일차 제출란의 HTML 파일 업로드 항목에 첨부한다. (10MB 미만)

### 재현용 프롬프트
```text
첨부한 kr_claims.xlsx의 claim 시트로 단독 실행 가능한 한국어 HTML 그래프를 만들어줘.
주제는 "호흡기 질환 청구는 겨울철에 더 많을까?"이고 독자는 병원 경영기획 담당자야.
main_sick가 J로 시작하는 행만 골라 recu_fr_dd를 YYYY-MM으로 묶고 행 수를 집계해.
2024-01부터 2025-12까지 24개월을 시간순으로 배치한 꺾은선 그래프를 그려줘.
가로축은 진료월, 세로축은 명세서 수(건)이며 세로축은 반드시 0부터 시작해.
SVG로 구현하고 모든 스타일을 HTML에 넣어 인터넷 없이 열리게 해줘.
24개월 원자료 표도 접고 펼칠 수 있게 넣어줘.
11~3월 10개월의 월평균과 6~9월 8개월의 월평균을 비교하고 배율을 계산해.
예상 검산값은 742.1건, 341.875건, 약 2.17배야. 다르면 원자료를 확인하고 수치를 강제로 맞추지 마.
가상 데이터임을 표시하고 전국 질환 발생률이나 인과관계로 해석하지 마.
원본 시트 링크를 출처에 넣고 파일 이름은 graph.html로 해줘.
```

## 과제 2 — 본인 대시보드 완성

### 공개 URL
배포 설정 및 성공 확인 후 `https://EMEM-Kim.github.io/nano_dee/dashboard.html`을 입력한다. 이 주소는 예정 주소이며, 배포 전에는 제출하지 않는다. 설정 절차는 [배포 안내](deployment.md)를 따른다.

### 결과 정리
**독자·빈도·목적:** 이 페이지는 병원 경영기획 담당자가 월초 경영회의 전에 청구 규모, 상병 구성과 계절별 진료 수요를 점검하기 위해 본다.

**KPI:** 총 명세서 수 38,375건, 총 진료비 3,293,580,300원(약 32.94억 원), 수진자 수 2,970명이다. 수진자 수는 jid를 중복 제거해서 계산했다.

**차트:** 주상병별 명세서 수 TOP 8은 가로 막대그래프로 비교한다. 기관 종별 건당 진료비도 가로 막대로 비교한다. 호흡기 질환의 월별 명세서 수는 꺾은선으로 추세를 보여준다.

**한 줄 인사이트:** 급성 기관지염(J209)이 5,285건으로 가장 많고, 호흡기 질환 청구의 11~3월 월평균은 6~9월의 약 2.17배다.

**추가 기능:** 연도·기관 종별·상병 범위 필터가 KPI와 모든 차트에 동시에 적용된다. 월별 원자료 표와 CSV 다운로드를 제공해 차트의 숫자를 직접 확인할 수 있다.

**해석:** 상급종합병원의 건당 진료비는 약 499,558원, 의원은 약 36,019원이다. 입원 비중과 상병 중증도 등을 조정하지 않은 단순 평균이므로 기관의 효율이나 진료의 질로 해석하지 않는다. 수업용 가상 데이터에서의 관찰이다.

### 재현용 프롬프트
```text
kr_claims.xlsx를 사용해 CareLens라는 한국어 건강보험 청구 대시보드를 만들어줘.
독자는 월초 경영회의를 준비하는 병원 경영기획 담당자이며 목적은 청구 규모와 상병 구성, 계절 수요 확인이야.
claim과 institution을 yid로 연결하고 main_sick와 sick_master.sickcd를 연결해 상병명을 표시해.
기관 종별명은 code_table의 code_type='종별코드'인 값으로 매핑해.
먼저 claim.mid와 institution.yid 중복 여부, 기관 조인 누락을 확인해.
KPI는 명세서 행 수, rvd_rpe_tamt_amt 합계, 고유 jid 개수 3개로 해줘.
차트는 주상병별 청구 건수 TOP 8 가로 막대, 기관 종별 건당 진료비 가로 막대,
main_sick가 J로 시작하는 호흡기 질환의 월별 청구 건수 꺾은선 3개야.
날짜는 recu_fr_dd, 건당 진료비는 총 진료비/건수로 계산해.
연도, 기관 종별, 전체/호흡기 상병 필터를 모든 KPI와 차트에 같이 적용해.
수진자 수는 필터가 바뀔 때마다 고유 jid를 다시 세고 월별 수진자를 합산하지 마.
겨울철(11~3월)과 여름·초가을(6~9월)의 월평균 비교를 계산해 한 줄 인사이트를 보여줘.
월별 집계표와 UTF-8 BOM CSV 내려받기, 필터 초기화를 추가해.
수업용 가상 데이터임을 표시하고 실제 환자 기록이나 전국 통계로 주장하지 마.
정적 HTML/CSS/JavaScript와 SVG를 사용하고 모바일에서도 읽기 쉽게 만들어줘.
CSS와 데이터, 스크립트를 파일 안에 포함한 index.html 및 dashboard.html로 내보내줘.
원본 데이터로 독립 집계하여 총 38,375건, 3,293,580,300원, 2,970명을 검산해.
기준 수치와 다르면 오류를 찾아 수정하고 데이터를 지어내지 마.
GitHub Pages에 올릴 수 있도록 정리하되 실제로 배포하지 않았다면 배포됐다고 쓰지 마.
```

## 작업 내용과 시행착오 (1·2일차 공통 제출용)

- 원본 XLSX에서 claim, institution, sick_master, code_table을 읽고 조인 키와 중복을 검사했다.
- 기관 종별 매핑은 비슷한 이름의 코드 유형을 혼용하지 않도록 `종별코드`만 선택했다.
- 명세서 수와 환자 수를 구분하고, 필터 적용 후 고유 환자 수를 다시 계산하도록 구현했다.
- HTML 템플릿에 데이터와 스타일을 포함해 한 파일만 열어도 결과가 재현되도록 했다.
- 전체 값과 2025년·의원 필터 결과를 원자료 집계와 비교했다.
- 배포 파일 업로드와 웹 공개 설정은 별개이므로, 파일 업로드만으로 공개 URL이 열렸다고 간주하지 않는다.
